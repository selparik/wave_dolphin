## 2. Демонстрация

```python
from wave_dolphin import WaveDolphin, DolphinNoStrength

vehicle = WaveDolphin(
    "Волновой Дельфин", mass_kg=120, fin_span_m=2,
    max_speed_kmh=60, energy=80,
)

print("Начало:", vehicle.get_status())
vehicle.move(10, "air")
print("После полёта:", vehicle.get_status())
vehicle.move(5, "water")
print("После возвращения:", vehicle.get_status())

print("Волна преодолима:", vehicle.can_overcome("wave"))
print("Скала преодолима:", vehicle.can_overcome("cliff"))
```

## Назначение

«Волновой Дельфин» — гибридный транспорт водной стихии. Он перемещается по поверхности воды, под водой и в упрощённом режиме полёта над водой. Конструкционные элементы: два складывающихся гидродинамических плавника и водомётный движитель.

## Публичный интерфейс

Класс `WaveDolphin` находится в `wave_dolphin.py`. Реализованы `move`, `can_overcome`, `calculate_energy`, `refuel`, `get_status`, а также доменные исключения из SPEC 0.2.

| Режим | Скорость | Расход энергии |
|---|---:|---:|
| `water` | `max_speed_kmh * 0.5` | 1 ед./км |
| `underwater` | `max_speed_kmh / 3` | 2 ед./км |
| `air` | `max_speed_kmh` | 2 ед./км |
| `ground` | запрещён | `DolphinCannotWalk` |

Энергия ограничена диапазоном 0…100. Заправка возможна только на поверхности. При ошибках состояние объекта не меняется.
